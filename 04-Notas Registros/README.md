# Calculadora de Promedio de Notas 📊

Programa que permite ingresar varias notas y calcula el promedio, la nota más alta y la más baja.

## 🎯 ¿Qué hace?

1. Pregunta cuántas notas se van a ingresar
2. Pide cada nota una por una
3. Calcula el promedio, la nota más alta y la más baja

## 📚 Lo que aprendí

- Listas (`[]`) para guardar varios valores
- `.append()` para agregar elementos a una lista
- Bucle `for` con `range()`
- Funciones integradas: `sum()`, `len()`, `max()`, `min()`
- Uso de `\n` para saltos de línea dentro de un mismo `print()`

## 🚀 Cómo ejecutarlo

```
python promedio_notas.py
```
