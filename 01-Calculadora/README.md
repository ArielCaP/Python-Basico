# Calculadora en Python 🔢

Calculadora básica que permite hacer sumas, restas, multiplicaciones y divisiones entre dos números.

## 🎯 ¿Qué hace?

1. Le pide al usuario dos números
2. Le pregunta qué operación quiere realizar (+, -, *, /)
3. Muestra el resultado
4. Evita el error de dividir entre cero, avisando al usuario en vez de romper el programa

## 📚 Lo que aprendí

- Uso de `input()` para interactuar con el usuario
- Conversión de tipos con `float()`
- Condicionales `if / elif / else`
- f-strings para mostrar resultados de forma más clara
- Manejo básico de errores (división entre cero)

## 🚀 Cómo ejecutarlo

```
python "Calculadora-Basica con condiciones.py"
```
